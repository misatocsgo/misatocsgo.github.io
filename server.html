Requirements

  • Counter-Strike 2
  • Tailscale
  • Access to the misatoCSGO Tailscale network
  • Authorized device

Connecting

  1. Install Tailscale.
  2. Sign in.
  3. Make sure your device is authorized.
  4. Connect to Tailscale.
  5. Open Counter-Strike 2.
  6. Open the developer console.
  7. Enter the command below.
connect 100.84.231.72:27015

Important

The server is not directly exposed to the public internet.

Tailscale access is required before connecting.

Administrator permissions may be required to install Tailscale on Windows.
